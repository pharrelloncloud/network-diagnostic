# network-diagnostic  
This script is a network diagnostic tool that outputs the following.

## IP Configuration  
This is who am I on the network

### Routing Table   
This is where I send things

## DNS Test  
This tests to see if I can find websites by name

## Connectivity Test  
This tests if I can actually reach the internet by sending packets and seeing how many come back and the time it takes.

## Network Interfaces  
This shows me who is currently talking ie the eth0 or lo or both or none.
